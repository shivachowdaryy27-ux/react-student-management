# 🎓 React Student Management App

A simple and interactive Student Management Application built using **React.js**.

## 🚀 Features

- Display student information
- Create reusable React components
- Pass data using Props
- Manage state using `useState`
- Handle button click events
- Track student enrollment

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## 📚 Concepts Practiced

- JSX
- Functional Components
- Props
- State Management
- Event Handling
- Component Reusability
